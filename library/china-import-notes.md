# 中国项目资料说明

整理日期：2026-09-21。

## 收录范围

来源为用户提供《明细&汇总-全球镍生铁-月度产量 060426.xlsx》和《中国纯镍硫酸镍项目.xlsx》。本次读取中国企业的89条镍生铁行、73条硫酸镍行、28条纯镍产线，合并为170个研究档案，涉及24个省级地区。记录是企业／产品／产线统计范围，不自动等于独立工厂。

镍生铁序列的月份列覆盖2017—2027年；硫酸镍为2020年3月—2026年9月；纯镍为2013年1月—2026年9月。各行实际填数范围不同。表头及重复值不足以证明数据全部为实际产量：未收到逐月实绩／预测分界说明前，统一称“原表月度记录”。2026年9月及以后默认不显示，勾选后保留“未完结／未来列”标签。

## 合并规则

- 同一企业同省份的明确A、B产线归入一份档案，但保留独立产线数值。
- 广西银亿等能直接对应的纯镍与硫酸镍条目共用项目入口，两个产品不相加。
- 金川电解与电积、中伟一期与二期共用相应基地入口，保留分线序列。
- 纯镍表金川、华友、华泽、中伟四条集团合计行不作为新增工厂，也不与子产线重复加总。
- 山西曲沃三鑫、光大冶金大连及鑫峰现名、辰东化工的明确重复或简称行，逐月补齐缺值，不把重叠产量相加；原行可以单独查看。
- 和谊／万汇租赁行及瑞泰／永鑫历史抬头尚需对应具体产线，保留独立入口，暂不加入默认样本合计。
- 陕西聚泰硫酸镍行在陕西，纯镍行列在浙江，分别保留；总部地址不代替实际厂址。
- 湖南中伟和浙江华友的硫酸镍行可能采用公司统计范围，不将其月度量直接归入钦州、广西或衢州单厂。

## 数值处理

从逐厂明细读取保存的数值，不引用存在#NAME?、#REF!等错误的汇总结果。相关中国明细中识别到8918个错误单元格，多数涉及开工率或失效公式；错误不改成零。未修改原始工作簿，也未声称重新执行其全部公式。

已按连续月份列序及相邻日期恢复4处缺少日期的表头：镍生铁2022年12月、2027年6月、2027年10月，硫酸镍2024年5月；纯镍2023年7月日期虽错位，仍在同一月份块内，按列名对齐。月份块宽度改变时按字段表头解析，不固定套用列数。

实物吨与镍吨分开。纯镍表的“总产能／总产量”保存原始数值并显示原表吨口径，不擅自把月产能乘12改写成设计年产能。全年与不完整年度不直接比较。

硫酸镍的原料用量与纯镍按原料类别划分的产量不是同一指标；可流通量中的负值保留为差额，不视为负销售量。月度样本合计注明有数行数，缺数不填零，不包装成全国总产量。

## 企业资料核对

中伟钦州、华友玉林与衢州补入公司披露的主体、产品与品牌注册事件；注册时间不写成投产时间。NNI低冰镍到钦州的供料关系连接回原印尼条目，并与高冰镍湿法生产电解镍环节区分。金川镍盐与金昌纯镍产线分别建档。

其余工厂的股东、设备数量、投产历史和当前开工状态仍按后续研究补齐，本次不会用统计首月代替投产年，也不会以零值／空白直接认定永久停产。
